# 💬 Talk-A-Tive — Real-Time Chat Application

Talk-A-Tive is a **real-time web-based chat application** that allows users to communicate through an interactive and responsive messaging interface.

The project was developed to gain hands-on experience with **full-stack web development, REST APIs, database integration, authentication, and real-time communication**.

## 🚀 Features

* 👤 User registration and login
* 🔐 User authentication
* 💬 One-to-one real-time messaging
* 👥 User search and chat selection
* 📱 Responsive chat interface
* 🔔 Message and chat notifications
* 🗄️ Persistent message and user data
* ⚡ Real-time communication
* 🌐 REST API based backend

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Asrjadhav/WebApp---Talk-a-Tive.git
```

### 2. Navigate to the Project

```bash
cd WebApp---Talk-a-Tive
```

### 3. Install Dependencies

Navigate to the application directory and install the required dependencies:

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and add the required configuration such as your MongoDB connection string and authentication settings.

Example:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 5. Start the Application

```bash
npm start
```

The application will start on the configured local development port.
